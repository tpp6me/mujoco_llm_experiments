# Supported G1 mechanical qualification — V4 protocol

Frozen: 2026-09-11, before the V4 held-out matrix. Status/results are maintained
in `../V4_RESULTS.md`; do not change this protocol after scored trials begin.

## Question and changes

Can centering the carried object over the basket and withdrawing vertically
qualify the conventional supported-body baseline without changing the V3 task,
physics, scoring thresholds, or 25-second simulation deadline?

Per-step V3 diagnosis placed the four excessive-penetration events during hand
opening (312, 365, 373) or diagonal withdrawal (352). The gripped block is offset
from the hand site, so a fixed hand target does not necessarily center the block.
Opening can catch it against the basket, and diagonal withdrawal can recontact it.
All four placement failures accumulated less than two seconds of qualifying dwell
by the deadline. These observations motivated a revised release sequence.

## Fixed conditions

- Unchanged pinned G1 model, supported pelvis, 43 actuators, ready-pose reset,
  hand targets/forces, solver settings, contact geometry, table, and basket.
- Unchanged free 5 × 7 × 12 cm, 60 g block; reset-only object state initialization.
- Nominal XY = (0.24, −0.18) m; independently uniform ±1.5 cm X/Y and ±0.15 rad yaw.
- Basket XY = (0.18, −0.36) m; floor Z = 0.712 m; rim Z = 0.84 m;
  horizontal interior half-widths = 0.085 m.
- Physics timestep 1 ms, implicitfast, 50 iterations; all scene bytes must match V3.
- One exact-state conventional controller, one simulation at a time, no LLM,
  no concurrent rendering, no synchronization to wall time.
- Qualification seeds: **400–499**, 100 episodes. Do not tune on these seeds.
- Seeds 0–19 and 100–399 are development/history; V3 failures and development
  probes are not independent evidence of qualification.

## Controller sequence

1. Read the object XY; add 0.015 m to the hand target X for palm clearance.
2. Approach at Z = 0.975 m; descend to table height +0.075 m; close the hand.
3. Require thumb and finger contact; lift to Z = 0.975 m; hold 0.5 s;
   require object bottom above table +0.04 m.
4. Carry the hand to (0.19, −0.36, 0.975) m.
5. Observe the carried object and hand. Compute release XY as basket XY plus
   (hand XY − object XY), cap hand target X at 0.235 m to stay inside the tested
   fixed-orientation reach envelope, and set hand target Z to 0.86 m.
6. Move to that pose; open the hand; lift vertically at the same target XY to
   Z = 0.975 m before moving to the parked pose (0.24, −0.18, 0.975) m.
7. Hold six seconds. Including reset settling (0.5 s), the nominal episode lasts
   25 simulated seconds. Each move/hand action lasts two seconds. The extra
   vertical move replaces two seconds of the previous final hold.

Release alignment is a conventional policy decision using explicitly supplied
object truth, not an implicit correction in `move`. The primitives still execute
the requested poses. No automatic retry, object reset, or recovery within a trial.

## Outcomes and gate

The V3 scorer criteria remain unchanged:

- Sustained lift: object bottom > table +4 cm with right-hand contact for ≥0.2 s.
- Placement: full bounding box inside basket (including below rim), direct floor
  support, no right-hand contact, and grasp site >12 cm from object center.
- Speed <2 cm/s and angular speed <0.15 rad/s for at least two seconds.
- Containment tolerates 0.5 mm compliant contact penetration; revoke arrival if
  any placement condition ceases to hold.
- Strict success additionally requires maximum object penetration ≤2 mm, no
  controller exception, and completion no later than 25 s (1e-6 s numerical tolerance).
- Gate: **at least 95/100 strict successes**. Keep all failures in the denominator.

Save every trial before starting the next. Record peak penetration time, contacting
body/geom ID, and associated normal force, plus cumulative score after each action.
Contact times identify the reported physics step (1 ms resolution). This telemetry
is private evaluation data, not a future visual policy input. Hash this protocol,
scene, and implementation; retain raw trajectories and a frozen source archive.
Report task success and strict success separately. Do not extend deadlines,
relax tolerances, or selectively rerun failed qualification seeds.
