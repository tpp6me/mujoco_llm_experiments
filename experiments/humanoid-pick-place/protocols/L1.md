# Frozen L1 exact-state LLM development pilot

Date: 2026-09-11. Freeze before live requests on seeds 700, 701, 702.
This is a three-seed development pilot, not a confirmatory benchmark.

Compare GPT-5.6 Sol (`gpt-5.6-sol`, reasoning low) against the G2 conventional
policy on each identical randomized initial state. Conventional runs first;
LLM runs receive no conventional actions, outcomes, source files or scorer state.
The model receives the public exact-state observation, static task/robot contract,
its own previous actions and responses, remaining simulation time and action count.
No images or visual perception are used. No tuned pickup recipe or offsets are
provided. Both policies use interface v2 through the same deadline/action wrapper.
The conventional policy retains its explicit 0.88 m release and 0.4 opening.

Use the frozen supported G1 scene and independent mechanical scorer unchanged.
Deadline: 25 simulated seconds including reset; maximum 20 attempted actions.
Require explicit individual move/hand/hold primitives, including waiting to settle.
The runner may add only schema version, fixed instruction version 1 and request ID;
it must not correct targets, choose recovery, insert motions or stop on private
success. A rejected action terminates either policy's episode. No retry, recovery,
seed replacement or exclusion. An API error, refusal, incomplete/malformed response,
missing credentials, local budget limit or timeout terminates the LLM episode and
remains in the results. Physics is paused during model calls. Run sequentially;
no concurrent physics tests or rendering.

Use the Responses API with store=false, strict JSON schema output, no external
tools, maximum 2048 output tokens per call and 45-second urllib socket timeout.
Record requested/returned model, raw request and response, response/request IDs,
provider status/service tier, usage and local API round-trip time. Do not interpret
round-trip wall time as isolated model inference time. Do not log credentials.

Pilot budget: at most $5 under the local estimate/reservation system. Standard
rates verified 2026-09-11: $4/M uncached input, $0.40/M cached input, $20/M output.
Before each call reserve a conservative byte-based input estimate plus maximum
output cost; pending, interrupted and unknown-usage calls retain their reservation.
This is not a guarantee about provider invoices. No pricing-based performance
claim is made. Preserve reports and partial state after every action and attempt.

Strict outcome requires physical task success, maximum object penetration ≤2 mm,
no policy/runtime error, and completion within 25 s. Report task/contact quality,
action/model-call counts, provider usage and errors separately. Do not apply the
100-trial mechanical gate to this three-case pilot. A negative result is valid.
Archive sources, prompt/schema hashes, seeds, configuration and all attempts.

Official references used for implementation:

- https://developers.openai.com/api/reference/python/resources/responses/methods/create
